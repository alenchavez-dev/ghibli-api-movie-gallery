# 🎬 Ghibli API Movie Gallery

A responsive front-end web app that fetches and displays Studio Ghibli films using a live API.  
Built with **HTML**, **CSS**, and **JavaScript**, this project demonstrates API integration, DOM manipulation, and responsive design.

---

## ✨ Features
- Fetches real Studio Ghibli film data from a hosted API
- Dynamically generates movie cards with titles and descriptions
- Responsive, mobile-friendly design
- Gradient card headers with hover effects
